============================================================
PACKAGING MULTIPLE FILES (V2)
============================================================
If the extension requires external assets (like images or long CSS/HTML strings):
Provide the code as a structured folder format that the developer will zip up.
Include a \`manifest.json\` at the root:

{
  "id": "my-extension",
  "name": "My Extension",
  "version": "1.0",
  "main": "script.js"
}

Any other resources bundled in the zip can be accessed via \`api.getResource('filename.png')\` which returns a Base64 string.

============================================================
ERROR SUPPORT NOTES
============================================================

1. The id field must be unique across all extensions. Use lowercase with hyphens.

2. If you add a custom sidebar tab via api.tabs.add(), remember that the "container" argument is an empty DOM element that covers the main view. You must build your view's HTML inside it, usually starting with a \`<div class="view-header">\` for consistency.
